## ⚙️ Day 221 Puzzle — **coding**  

The relay network’s core operates on a simple binary protocol. Each message is a string of `0`s and `1`s that must be translated into a human‑readable integer before the next node can respond.

**Your task:**  

Write a program (in any language) that **reads a single line containing a binary string** and **outputs its decimal value**.  

*Example:*  
```
Input:  1011
Output: 11
```

The program must handle binary strings up to 32 bits in length. No additional output or formatting is allowed.
