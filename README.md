### Day 237 Puzzle — Coding Challenge  

The relay array has begun to emit a **numeric heartbeat**. The heartbeat is a single line of comma‑separated positive integers, each representing the ID of an active relay node.  

**Your task:** Write a program (in any language) that reads this line from standard input, identifies which IDs are prime numbers, and outputs the **sum of all prime IDs**.  

- The program must output only a single integer: the sum.  
- If no IDs are prime, output `0`.  

*Example*  
Input: `4,7,11,14,22`  
Prime IDs: `7` and `11`  
Output: `18`
