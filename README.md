### Day 211 Puzzle — coding  

The network has intercepted a burst of raw binary data from an unknown source. Your task is to **write a program** that:

* reads a single line from standard input containing a binary number (a string of `0`s and `1`s, e.g., `101101`),  
* converts that binary string to its decimal (base‑10) representation, and  
* prints the decimal number to standard output.

The program must handle any length of binary input that fits within the language’s native integer range.

*Example:*  
Input: `1101`  
Output: `13`

---

## Hints  

1. The conversion you need is a classic **base‑2 to base‑10** operation.  
2. The input will be a **single line** composed only of the characters `0` and `1`.  
3. Most languages provide a built‑in way to **parse a string as an integer with a specified base**; use it, then output the result.
