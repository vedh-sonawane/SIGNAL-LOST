## 🚀 Day 175 Puzzle — **coding**  

**Objective:** Write a program that translates a space‑separated binary string into its ASCII representation.

**Input (hard‑coded for the puzzle):**  

```
01001000 01100101 01101100 01101100 01101111
```  

**Required behavior:**  

- The program must read the binary values (each 8 bits) separated by spaces.  
- Convert each 8‑bit group to its decimal ASCII code.  
- Output the concatenated characters as a plain string.  

*Example:* For the input above, the correct output is:

```
Hello
```  

**Submission:** Your PR should contain a file `solutions/day175.md` that includes the source code (in any language) and a short explanation of how it works.
