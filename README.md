### How to Play
To participate, follow these steps:
1. **Solve the Puzzle**: Read the daily puzzle in this README and solve it.
2. **Submit Your Solution**: Create a new file under the `solutions/` directory based on `solutions/TEMPLATE.md`, detailing your solution.
3. **Open a Pull Request**: Submit your solution as a Pull Request to this repository.
4. **Suggest Lore Twists**: Open an Issue with your ideas for new lore, helping to shape the narrative.
