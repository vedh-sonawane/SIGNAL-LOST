## 🧩 Day 160 Puzzle — **coding**

```
RX4G 7X2V Z1YQ
```

Your task: **Write a program (in any language) that reads a single line containing the relay’s broadcast string (uppercase letters, digits, and spaces) and outputs the number of distinct **alphabetic** characters present, ignoring spaces, digits, and case.**  

*Example:*  
Input: `ABa C1D2` → Output: `4` (letters A, B, C, D).  

Submit a solution file that includes your source code and a brief description of how to run it.
