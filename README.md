## How to Play  

1. **Read the transmission.** Every day a new puzzle is embedded in the README.  
2. **Solve the puzzle.** When you think you have the answer, open a Pull Request that **adds a file** under `solutions/` using the template at `solutions/TEMPLATE.md`.  
3. **Earn your place in the Hall of Fame.** Solvers and lore contributors are credited in the README on the following day.  
4. **Suggest new twists.** Have an idea for the story? Open an Issue titled *Lore Suggestion* and describe your twist.  

### Community Rules  

- **Solutions:** PRs must add a file under `solutions/` (e.g., `solutions/your‑username‑day231.md`) based on the provided template.  
- **Lore:** New story ideas belong in Issues. Closed lore issues are noted in the transmission log.  
- **Credit:** Tomorrow’s README will list today’s solvers and lore suggesters by GitHub username.

- Accept a single line of input (the encoded phrase).  
- Apply the Atbash substitution (A↔Z, B↔Y, …, Z↔A).  
- Print the resulting English sentence.
