## Day 213 Puzzle — Coding Challenge  

The orbital relay has begun emitting a continuous string of status characters, each an uppercase letter **A‑Z**. Your task is to write a program that:

* Reads **one line** from standard input containing the status string (no spaces).  
* Counts how many **distinct letters appear exactly three times** in that string.  
* Prints that count as an integer to standard output.

**Example**  

```
Input:  AAABBBCCCDDDE
Output: 3
```

(‘A’, ‘B’, and ‘C’ each occur three times.)

> **Note:** The puzzle must be solvable using only the information in this README.
