### Day 143 Puzzle — Coding Challenge
Write a Python function `decode_signal` that takes an integer `signal` as input and returns the binary representation of the signal with all occurrences of '1' replaced with '0' and vice versa. The function should also count the number of bits changed during this process and return the count.

Example input: `signal = 10` (binary: 1010)
Expected output: (`binary_string`, `bit_changes`) = ('0101', 2)
