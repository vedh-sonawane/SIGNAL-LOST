### Day 217 Puzzle — Coding Challenge  

Write a program that processes a stream of signed integers, one per line, until it encounters a line containing only `0`. The program must:  

1. Identify which of the read numbers (excluding the terminating `0`) are **prime** (a prime is a positive integer greater than 1 that has no positive divisors other than 1 and itself).  
2. Compute the **sum** of all prime numbers found.  
3. Output **exactly one line** containing that sum as a decimal integer.  

*The input may contain negative numbers, zeros (only the terminating one), and non‑prime positives. Only positive primes contribute to the sum.*
