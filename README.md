## 📂 Day 179 Puzzle — **Coding**

> **Objective:** Write a program (in any language) that reads **one line** containing **three space‑separated integers** `A B C` (the last three relay ping timestamps, in seconds). The program must output the **median** of the three numbers — the value that would appear in the middle if the three were sorted in ascending order.

*Example*  
Input: `42 17 93`  
Output: `42`

*Your code should:*  
- Accept input from standard input.  
- Print **only** the median integer to standard output.  
- Not rely on any external libraries beyond the language’s standard runtime.
