## How to Play  

1. **Read the README** – All clues, lore, and puzzles are contained here.  
2. **Solve the daily puzzle** – Each day a new challenge appears (coding, cipher, riddle, or logic).  
3. **Submit your solution** – Open a Pull Request that adds a file under `solutions/` based on `solutions/TEMPLATE.md`.  
4. **Suggest new lore** – Open an Issue titled *Lore Suggestion* with your idea.  
5. **Tomorrow’s README** will credit today’s solvers and lore contributors by GitHub username.
