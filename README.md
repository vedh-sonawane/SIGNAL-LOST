### Day 189 Puzzle — coding

The relays have been logging their status in a file called **`relay_log.txt`**. Each line follows the format:

```
<ISO‑8601 timestamp> <3‑letter status code>
```

Example lines:

```
2026-10-10T12:00:00Z OK
2026-10-10T12:01:15Z ERR
2026-10-10T12:02:30Z OK
```

**Your task:** Write a program (in any language) that reads `relay_log.txt`, counts how many lines contain the status code **`ERR`**, and outputs that count as a single integer.

*The program does not need to handle malformed lines; you may assume every line conforms to the format above.*
