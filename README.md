## How to Play  

1. **Read the transmission.** All clues, story, and puzzles are contained within this README.  
2. **Solve the daily puzzle.** Each day rotates between coding, cipher, riddle, and logic challenges.  
3. **Submit your solution.** Fork the repository, add a file `solutions/<your‑username>.md` using the provided template, and open a Pull Request.  
4. **Suggest lore.** Want to twist the story? Open an Issue with your idea.  

*Only the first correct solution each day will be credited in the Hall of Fame.*

## Community Rules

- **Lore suggestions** are to be opened as Issues and may be closed if they don’t fit the narrative.
