## 🧩 Day 177 Puzzle — **Coding Challenge**  

The relay is still emitting a raw binary stream. Your task:

> **Write a program** (in any language) that reads a file named `signal.txt`.  
> The file contains a series of **space‑separated 8‑bit binary numbers** (e.g., `01001000 01100101 01101100 01101100 01101111`).  
> Your program must **convert each 8‑bit group to its ASCII character** and output the resulting plaintext message as a single line.

*The solution file you submit should contain the source code and a brief comment explaining how to run it.*
